# DevTools Hub 🧰

A polished collection of small, dependency-free developer utilities in one fast browser interface.

## 🧰 Included

- JSON Formatter
- JSON Diff
- Base64 Encoder/Decoder
- URL Toolkit
- UUID Generator
- Color Converter
- Regex Tester
- Timestamp Converter
- Case Converter
- Hash Generator
- HTML Escape/Unescape
- Slug Generator

## ✨ Features

- Searchable tool catalog
- Category labels
- Responsive interface
- Fast static frontend
- Local-first design
- No framework or backend required

## 🚀 Run

Open `index.html` directly or serve the folder with any static web server.

## 🛠️ Philosophy

Each utility should be fast, understandable, dependency-light, and useful without creating an account.

## 🤝 Contributing

Add focused utilities, improve accessibility, refine the interface, or fix bugs. Keep tools dependency-free when practical.
