# DevTools Hub

A polished collection of small, dependency-free developer utilities.

## Included tools
JSON Formatter, JSON Diff, Base64, URL Toolkit, UUID Generator, Color Converter, Regex Tester, Timestamp, Case Converter, Hash Generator, HTML Escape and Slug Generator.

## Features
- Searchable catalog
- Fast static frontend
- Responsive UI
- Local-first concept
- No framework required

## Run
Open `index.html` in a browser.
